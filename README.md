# CarPulse – AI-Powered Car Price Prediction & Recommendation System

CarPulse is an AI-powered automotive platform designed to help users make smarter vehicle purchasing decisions. It combines machine learning-based car price prediction with an intelligent recommendation engine to provide data-driven insights into the automotive market.

🚗 **Live Demo:** [CarPulse Web Application](https://carpulse-ep6slj84g-acme-4a68.vercel.app)

---

## ✨ Features

- **Car Price Prediction:** Predict vehicle prices using a machine learning model.
- **Intelligent Recommendations:** Get vehicle recommendations based on available vehicle information.
- **AI-Powered Insights:** Leverage machine learning to support smarter automotive decisions.
- **Interactive Interface:** User-friendly dashboard for interacting with prediction and recommendation services.
- **Backend API Integration:** Connects with a FastAPI backend for real-time processing.
- **Model Health Monitoring:** Access backend health and model version information.

## 🏗️ System Architecture

CarPulse follows a frontend-backend architecture:

1. Users interact with the React-based frontend.
2. The frontend sends requests to the FastAPI backend.
3. The backend processes vehicle information.
4. The machine learning model generates price predictions.
5. The recommendation engine provides relevant vehicle recommendations.
6. Results are returned and displayed in the frontend.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https:/safi1232/github.com//car-frontend.git
```

### 2. Navigate to the Project Directory

```bash
cd car-frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the frontend root directory:

```env
VITE_API_BASE_URL=https://cars-8f427072.fastapicloud.dev
```

### 5. Run the Development Server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

### 6. Build for Production

```bash
npm run build
```

The production-ready files will be generated inside the `dist` directory.
